## 使用

1. 完整解压 Windows ZIP，双击 **Twin Cats.exe**。请保留同目录所有文件；升级前先从托盘退出旧版。
2. 点击摸头；普通拖动移动双猫，Shift＋拖动单独移动一只猫。
3. 右键猫咪或系统托盘打开设置、隐藏、唤回或退出。
4. 在 **设置 → 形象与大小 → 导入形象包** 中选择 `.twincats.json` 文件即可换形象。

支持独立动作、全屏或水平线活动、下班倒计时、今日待办和系统托盘。日常功能离线运行，设置与待办保存在本机。无需安装 Node.js。程序未作代码签名。
